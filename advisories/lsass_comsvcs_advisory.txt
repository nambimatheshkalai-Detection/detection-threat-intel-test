Threat Advisory: Credential Dumping via Comsvcs.dll
Threat actors frequently abuse the native Windows comsvcs.dll library to dump the memory of the Local Security Authority Subsystem Service (LSASS) process. By leveraging this technique, adversaries attempt to extract credential material, such as plaintext passwords or NTLM hashes, directly from memory. Attackers typically execute the command rundll32.exe C:\Windows\System32\comsvcs.dll, MiniDump <PID> lsass.dmp full. Security teams must ensure detection coverage for rundll32.exe executing with command-line arguments containing comsvcs.dll and the MiniDump function.
