Attackers remotely exploit critical zero-day vulnerabilities in internet-facing Citrix NetScaler ADC and NetScaler Gateway appliances. The vulnerabilities allow an unauthenticated attacker to trigger arbitrary command execution, memory corruption, service crashes, or denial of service through malicious HTTP/HTTPS or DTLS traffic.

After gaining control of the appliance, the attacker may download malicious tools, create or modify files, establish a web shell or other persistent access, create unauthorized administrator accounts, alter authentication or VPN policies, and disable or manipulate audit logging. Because the compromised NetScaler is a trusted perimeter device, the attacker may use it to communicate with external command-and-control infrastructure, steal or reuse VPN sessions, bypass expected authentication controls, access internal identity services, scan internal systems, and move laterally over protocols such as LDAP, Kerberos, SMB, SSH, RDP, or WinRM.

Observable behavior can include anomalous HTTP requests, repeated server errors, unusual DTLS activity, memory errors, core dumps, unexpected restarts, unauthorized configuration changes, new files in temporary or web-accessible directories, outbound connections to previously unseen public destinations, abnormal communication with internal systems, suspicious VPN sessions, and sudden interruption or deletion of NetScaler security logs.
